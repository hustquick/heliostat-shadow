# APP 外的镜场优化验算

本实验只增加 Python 脚本和报告，不改四端 APP、目录电厂数据或共享计算核心。光学评分复用已有 Rust 全场模型；模型不可用时使用 Python 参考实现。

## 两个改进的目的

物理方向辅助搜索用余弦/大气透射的有限差分方向、强耦合镜对的分离方向，补充东西南北移动。它旨在用较少方向覆盖有物理意义的变化；本版额外评估这些方向，所以可能更慢。只有同等时间预算对照才能证明加速，不能把提案质量等同于速度提升。

协同移动用于跨越单镜局部停滞：一面镜子单独挪动可能压缩邻镜间距或使另一面受损，两面一起挪动则可能获得净收益。本版验证镜对，尚未实现三面以上的区域优化。

## 区域怎么划分

1. 对全部镜对计算中心连线到入射光线、反射光线的垂直距离。镜子用外接球半径界定潜在影响范围，反射方向限制至瞄准点附近。
2. 潜在重叠指标按代表时刻的 DNI×持续时间加权，得到对称耦合图。它只是候选生成的几何代理，既不代表实际遮挡损失，也不提供剪枝上界。
3. 从强到弱检查镜对能否形成至少一个合法的联合移动，跳过不可动的镜对，再选互不重叠的镜对，最多 `--pair-limit` 组；每次接受移动后重新建图。没有地理扇区边界，也没有固定最近邻数量，但组数上限意味着不是穷举所有联合移动。
4. 尝试共同平移、沿中心连线相对拉开/靠近、沿垂直方向相对错开。碰撞检查针对同时更新后的完整布局。

当前建图使用搜索代表时刻，降低低太阳高度时刻的代表性会影响分组；这是需要增加代表时刻数量复验的限制。后续可以使用更密的年度节点建图，并按实际多边形重叠权重替换球体代理。

## 接受规则及约束

每一轮枚举每一面镜子在全部指定步长、全部定义方向上的候选，检查合法性后重算全场接收光能量，并选完整候选集中的最大净增益。协同模式同时比较全部逐镜候选和定义的镜对候选。代理不用于删掉合法候选。镜子可以在下一轮再次移动。

`candidate_argmax` 指有限候选集合的最大值，不能推导任意连续位置的全局最优。预算用尽也不能称为收敛。没有增益只意味着当轮定义候选没有增益。

边界采用初始镜子中心的凸包，是一个保守实验范围，不是实测用地边界；不识别道路、禁入区和地形。移动后中心距至少为两镜半对角线之和加间隙，镜面尺寸、高度及光学参数固定，瞄准点重新指向同一圆柱接收器。这仍然是光学布局实验，不是施工方案。

## 运行

在仓库根目录执行：

```sh
~/venv/bin/python -m scripts.experiment_field_search \
  --plant ps10 --samples 4 --steps 2 --rounds 1 --pair-limit 16 \
  --full-year --output reports/ps10_external_search_2026-10-04
```

三种模式各自从同一原布局出发：`grid` 使用四轴方向；`physics` 在此基础上加入物理方向；`cooperative` 再加入镜对候选。候选数不相等，应同时查看收益、评估次数及用时；本轮不是同预算算法排名。

搜索先将原有月/小时年度代表节点压缩成指定数量的天空方向，用加权最远点选代表，然后将其余节点分配给最近方向。持续时间与全年 DNI 积分守恒，但光学能量近似误差没有上界。`--samples 288` 保留所有月/小时节点；逐时全年复核仍独立进行。增加方向/时刻/步长及轮数可改善覆盖，同时显著增加计算量。

`--layout` 可读入保持目录镜子 ID、尺寸的已有 CSV，使用目录的气象和接收器配置。多塔联合优化暂不支持。

## 输出与验收

- `comparison.json`：输入来源、三个模式的统计及逐轮结果。
- 各模式 `summary.json`：全场能量、评估数、耗时、镜对及移动记录；协同阶段记录平移/相对移动的合法评估次数和最好净增益。
- `search_layout.csv`：搜索提出的布局。
- 指定 `--full-year` 后，独立逐时复核原布局及各候选。如果候选全年能量没有超过原布局及阈值，`validated_layout.csv` 回退原布局；`annual_accepted` 标记验收结果。
- 不指定 `--full-year` 时不会输出已验收布局，也不会声称年能量改善。

年能量是接收器入射光能量，不是发电量；气象来源、是否晴空估计和重建坐标以报告为准。同一配置下的比较不能替代实测验证。

## 下一阶段

先加密代表时刻、使用多个步长、运行多轮，观察组移动实际被接受的次数及全年收益。随后比较相同全场评估预算/时间预算下的收益曲线，再考虑三镜小区域、实际遮挡图和保守增量重算。任何增量方案都必须与全场重算校验一致，之后才考虑 APP 接入。
